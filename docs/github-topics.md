# GitHub 仓库主题词(About 区域)

> 把下面 20 个英文关键词直接复制到 **GitHub → 仓库 → About → Topics**,最大化在 GitHub 搜索 / Explore / Trending 里的曝光度。
>
> GitHub Topics 字段只能用英文(不支持中文),但 Repository Description 字段可以中英混合。

## 完整填写流程

1. 打开 https://github.com/nothingtosayyy/Mulberry-web
2. 右上角 ⚙️ **Settings**(或 About 区域右侧齿轮)
3. 找到 **About** 区块
4. 点 **Add description** → 粘贴上面任一版本
5. 点 **Add topics** → 粘贴那 20 个逗号分隔的词
6. **Website** 填部署地址
7. 保存

完成后在 GitHub 搜索 `blog-template` / `react-template` / `personal-blog` 时,你的仓库会出现在结果里。
